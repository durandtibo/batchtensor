# Utils API Reference

This page provides the complete API reference for the `batchtensor.utils` module.

The utils module contains the helpers that traverse nested structures of tensors, the `NestedTensor`
type, and the helpers that draw reproducible random permutations.

For usage examples and tutorials, see the [Utils User Guide](../uguide/utils.md).
